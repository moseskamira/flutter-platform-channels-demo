# Platform Channels Demo

A Flutter project demonstrating **Platform Channels (MethodChannel)** to communicate with native Android code.

---

## 🚀 Features

This project focuses on **Flutter ↔ Native Android integration**, including:

### 🔹 Platform Channels (Core Skill)
- Implementation of **MethodChannel**
- Communication between Flutter and native Android (Kotlin)
- Sending and receiving data between platforms

### 🔹 Native Ringtone Access
- Fetching **system ringtones from Android native platform**
- Returning ringtone list to Flutter via MethodChannel
- Displaying ringtones in Flutter UI
- Preparing for ringtone selection / playback features

---

## 🧠 Key Concepts Demonstrated

- Flutter Platform Channels
- MethodChannel (Flutter ↔ Android communication)
- Native Android integration with Kotlin
- Bridging system APIs with Flutter UI
- Working with device media (ringtones)

---

## 📱 What the App Does

- Calls native Android code from Flutter
- Retrieves available system ringtones from the device
- Sends ringtone data back to Flutter
- Displays ringtone list in a Flutter UI

---

## 🛠️ Technologies Used

- Flutter
- Dart
- Kotlin (Android native code)
- MethodChannel (Platform Communication)

---

## 📂 Project Purpose

This project is built as a **learning and demonstration project** to:

- Understand how Flutter communicates with native platforms
- Learn how to access device-level features not available in pure Flutter
- Practice real-world platform channel implementation patterns
